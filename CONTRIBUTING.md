# Contributing

Contributions, bug reports, improvements, and ideas are welcome.

## Before contributing

1. Keep API keys, passwords, tokens, and other secrets out of commits.
2. Run `npm install` before testing.
3. Test the application before submitting changes.
4. Preserve existing JARVIS Mark 7 functionality where possible.
5. Avoid duplicate Three.js scenes, renderers, animation loops, or camera streams.
6. Test mobile/Termux behavior when relevant.

## Pull requests

Please describe:
- What changed
- Why it changed
- How it was tested
- Any known limitations
